## About Me

<img align="right" alt="Developer working at a computer" width="300" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif"/>

### Current Priorities

- Strengthening programming and analytical skills
- Exploring machine learning workflows
- Improving backend development and software architecture
- Gaining hands-on experience through real-world projects

### Career Objective

To grow as a software developer by building useful applications, applying analytical thinking, and continuously improving my technical skills.
